# Production Deployment Guide: AWS EC2 (Ubuntu)
**Target Domain**: `aimarketing.analytx4t.com`  
**GitHub Repository**: `https://github.com/priyanshu442004/Marketing.git`  
**Target Branch**: `main`  
**Stack**: React (Vite SPA) + Node.js (Express API) + Prisma ORM + PostgreSQL + Nginx + PM2 + Let's Encrypt SSL

---

## 1. AWS EC2 Instance Setup
1. **Launch Instance**:
   - **AMI**: Ubuntu Server 22.04 LTS (64-bit x86)
   - **Instance Type**: `t3.small` or `t3.medium` (recommended)
   - **Key Pair**: Download and save your `.pem` key (e.g., `aimarketing-key.pem`)
2. **Security Group Inbound Rules**:
   - **SSH (Port 22)**: My IP / Any (`0.0.0.0/0`)
   - **HTTP (Port 80)**: `0.0.0.0/0`
   - **HTTPS (Port 443)**: `0.0.0.0/0`
3. **Elastic IP**: Allocate an Elastic IP and associate it with your EC2 instance.

---

## 2. DNS Configuration
In your DNS provider (Cloudflare / Route53 / Domain Registrar):
- Add **`A` Record**:
  - **Host / Name**: `aimarketing` (or `aimarketing.analytx4t.com`)
  - **Value**: `YOUR_EC2_PUBLIC_IP`
  - **Proxy status**: *DNS Only / Unproxied* (if using Cloudflare) until SSL is issued.

---

## 3. Server Setup via SSH

Connect to your EC2 instance:
```bash
ssh -i /path/to/aimarketing-key.pem ubuntu@YOUR_EC2_PUBLIC_IP
```

Update packages & install dependencies:
```bash
# Update Ubuntu packages
sudo apt update && sudo apt upgrade -y

# Install Git, Nginx, Certbot
sudo apt install -y curl git unzip build-essential nginx certbot python3-certbot-nginx

# Install Node.js 20 LTS & PM2
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
```

## 6. Nginx Reverse Proxy Configuration

Create site configuration:
```bash
sudo nano /etc/nginx/sites-available/aimarketing
```

Paste configuration:
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name aimarketing.analytx4t.com;

    client_max_body_size 20M;

    # Frontend SPA Build Directory
    root /var/www/Marketing/dist;
    index index.html;

    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    # React Client Router Fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API Proxy to Node Backend (Port 5000)
    location /api/ {
        proxy_pass http://127.0.0.1:5000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_connect_timeout 300s;
    }

    # Backend Health Check Proxy
    location /health {
        proxy_pass http://127.0.0.1:5000/health;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

Enable site & test Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/aimarketing /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

## 7. SSL Certificate Setup (Let's Encrypt)

```bash
sudo certbot --nginx -d aimarketing.analytx4t.com
```

Test auto-renewal:
```bash
sudo certbot renew --dry-run
```

  ```bash

  ```
- **View Backend Logs**:
  ```bash
  pm2 logs aimarketing-api
  ```

  ```bash
  cd /var/www/Marketing
  git stash
  git checkout main
  git pull origin main
  
  # Rebuild Frontend
  npm install
  npm run build

  # Restart Backend & Database Sync
  cd backend
  npm install
  npx prisma db push
  pm2 restart aimarketing-api

  # Reload Nginx
  sudo systemctl reload nginx
  ```
